# Network Final Lab · 01076040

เว็บภาษาไทยสำหรับเตรียมสอบปลายภาควิชา *Internetworking Standards and Technologies* (มาตรฐานและเทคโนโลยีเครือข่าย) รวม **8 บทเรียนทฤษฎี 22 งานปฏิบัติ ข้อสอบทฤษฎี 120 ข้อ และข้อสอบปฏิบัติ 8 ชุด รวม 64 ข้อ** โดยจับคู่หลักการของแต่ละบทกับการตั้งค่าและการตรวจผลจากใบงานที่ใช้เรียน

[เปิดเว็บทบทวน](https://toxxy180.github.io/NetworkY2_Final/) · [ดูขอบเขตสอบของอาจารย์ (PDF)](./แนวเนื้อหาข้อสอบปลายภาค_Network.pdf) · [เปิดโฟลเดอร์สไลด์และใบงาน](./network_files/)

หากต้องการอ่านออฟไลน์ ให้ดาวน์โหลดไฟล์ `index.html` ที่อยู่ด้านบนสุดของโครงการ แล้วเปิดไฟล์นั้นด้วยเบราว์เซอร์ได้ทันที

เมนู **ห้องทดลองเครือข่าย** มีสถานการณ์แบบโต้ตอบ 3 เรื่อง ได้แก่ การสลับ HSRP Gateway, การเลือกเส้นทาง OSPF และการส่งข้อมูลข้าม VLAN เลือกดูทีละขั้นหรือเล่นอัตโนมัติ สังเกตเส้นทางแพ็กเก็ตที่เคลื่อนไหว พร้อมคำสั่งและตัวอย่างผลในแต่ละช่วง กดเต็มจอหรือใช้ลูกศรซ้ายขวาขณะโฟกัสแผนภาพได้ หน้านี้เป็นภาพจำลองหลักการสำหรับเชื่อมกับการตั้งค่าในบทเรียน

## วิธีเตรียมสอบสองส่วน

เนื้อหาแยกหัวข้อ ย่อหน้า คำสำคัญ และรายการเปรียบเทียบให้ชัดเจน ส่วนงานปฏิบัติมีรายการเตรียมและทำตามลำดับครบ 22 งาน ปรับขนาดตัวอักษรได้จากเมนู **ตัวอักษร** ด้านบน; บล็อกคำสั่งใช้ฟอนต์แยกและคงบรรทัดสำหรับคัดลอก

เมนู **Openbook · A4 หน้า–หลัง** รวมชีทสำหรับคัดลงกระดาษตัวเล็ก แยก **ทฤษฎี 1 แผ่นหน้า–หลัง** (นิยาม เปรียบเทียบ สูตร และจุดสับสนครบ 8 บท) กับ **ปฏิบัติ 1 แผ่นหน้า–หลัง** (แม่แบบคำสั่ง Cisco IOS/Kali ค่าแลป วิธีตรวจและแก้ปัญหา) รวม 4 หน้า หน้าจอใช้ตัวอักษรขนาดอ่านง่าย ส่วน PDF และงานพิมพ์จัดแน่น 3–4 คอลัมน์

ดาวน์โหลด [ชีททฤษฎี A4 2 หน้า](./output/pdf/network-openbook-theory-a4.pdf) และ [ชีทปฏิบัติ A4 2 หน้า](./output/pdf/network-openbook-practical-a4.pdf) หรือเลือกชุดในเว็บแล้วกด **พิมพ์** ตั้งกระดาษ A4 แนวตั้ง ขนาดจริง 100% พลิกขอบยาว และปิดหัวกระดาษ/ท้ายกระดาษของเบราว์เซอร์ คำสั่งที่ยาวจนตัดบรรทัดในกรอบให้พิมพ์ต่อเป็นคำสั่งเดียว เปลี่ยนชื่อพอร์ตและ IP ให้ตรงโจทย์

- **ภาคทฤษฎี** เลือกเมนู **บทเรียนทฤษฎี** ฝึกตอบให้ได้ว่าเทคโนโลยีนั้นคืออะไร ใช้แก้ปัญหาอะไร และต่างจากเรื่องที่ใกล้กันอย่างไร แล้วทำข้อสอบจากเมนู **ข้อสอบทฤษฎี**
- **ภาคปฏิบัติ** เลือกเมนู **บทเรียนปฏิบัติ** อ่านโจทย์ แล้วฝึกตามชุดคำสั่งที่แสดงพร้อมความหมายทีละบรรทัด พับคำอธิบายได้เมื่อต้องการซ้อมจำด้วยตนเอง คำสั่งจากแลบแสดงพร้อมคอมเมนต์อธิบายท้ายแต่ละบรรทัดในกรอบโค้ดเดียวกัน ระบุโหมดและหน้าที่; ปุ่มคัดลอกเฉพาะคำสั่งตัดคอมเมนต์ออกให้ ตัวอย่างเช่น หลังตั้ง HSRP บน R1 และ R2 ให้ใช้ `show standby brief` ตรวจว่าเครื่องใดเป็น Active เครื่องใดเป็น Standby และทั้งคู่ใช้ Virtual IP เดียวกันหรือไม่
- **ข้อสอบปฏิบัติ** เลือกชุดตามเรื่องจากเมนู **ข้อสอบปฏิบัติ** ฝึกเขียนคำสั่งเดี่ยว เขียนทั้งชุด เติมบรรทัดที่หาย และแก้ชุดคำสั่งผิด ชุดละ 8 ข้อ เปิดเฉลยรายข้อเพื่อทบทวน หรือส่งทั้งชุดเพื่อดูคะแนนและบรรทัดที่ต้องแก้ ระบบตรวจเทียบคำตอบที่เตรียมไว้และรองรับคำย่อที่แสดงในหน้าสอบ การตรวจผลการตั้งค่าบนอุปกรณ์จริงทำตามบทเรียนประกอบได้

เมื่อเพิ่มข้อสอบ คำตอบเดิมยังเก็บไว้ให้ทำต่อ ส่วนคะแนนสูงสุดเริ่มนับตามชุดใหม่ 8 ข้อ

คำตอบปฏิบัติที่กำลังทำ คะแนนสูงสุดแต่ละชุด และบทปฏิบัติที่อ่านแล้วบันทึกในเบราว์เซอร์ที่อนุญาต localStorage โดยมีความคืบหน้าของทฤษฎีและปฏิบัติแยกกัน

ในหน้าบทเรียน สารบัญจะไฮไลต์หัวข้อที่กำลังอ่านตามการเลื่อนหน้า กดวงกลมข้างชื่อหัวข้อหรือปุ่มท้ายหัวข้อเพื่อมาร์คว่าอ่านแล้วและกดซ้ำเพื่อยกเลิก เมื่อกลับมาเปิดบทเดิม ใช้ปุ่ม **อ่านต่อจากหัวข้อล่าสุด** เพื่อกลับไปยังหัวข้อที่บันทึกไว้ บนมือถือมีสารบัญแบบพับเก็บได้เหนือเนื้อหา เครื่องหมายของทฤษฎีและปฏิบัติบันทึกแยกกันในเบราว์เซอร์

ถ้าจำชื่อคำสั่งได้แต่จำบทไม่ได้ ให้พิมพ์คำสั่ง เช่น `show interfaces trunk` ในช่องค้นหาของเว็บ เมื่ออ่านจบแต่ละบท มีข้อสอบฝึก 15 ข้อพร้อมคำอธิบายเฉลย และมีชุดสุ่มรวม 30 ข้อสำหรับทบทวนข้ามบท โจทย์เหล่านี้เรียบเรียงขึ้นเพื่อฝึกตามขอบเขตสอบ

## หัวข้อและงานปฏิบัติทั้ง 8 บท

| บท | สิ่งที่ควรอธิบายได้ | ตัวอย่างงานที่ใช้ซ้อม |
| --- | --- | --- |
| 1 · Ethernet Switching | สวิตช์เรียนรู้ MAC อย่างไร และ Port Security แต่ละโหมดทำอะไรเมื่อเกิด violation | ตั้งค่า SW1/SW2 จาก console อ่าน MAC address table และกู้พอร์ตที่เข้า `err-disabled` |
| 2 · VLAN และ Trunk | Access port, trunk และ native VLAN ต่างกันอย่างไร และ VTP กระจายข้อมูลอะไร | กระจาย VLAN จาก server ไป client ตรวจ native VLAN ทั้งสองฝั่ง และปิด DTP ที่พอร์ตผู้ใช้ |
| 3 · Spanning Tree | STP เลือก root bridge และพอร์ตสำรองอย่างไร ทำไม BPDU Guard จึงใช้กับพอร์ตปลายทาง | อ่าน Root ID และ Port Role จาก `show spanning-tree vlan 1` แล้วทดสอบ BPDU Guard |
| 4 · Inter-VLAN Routing | Router-on-a-Stick ส่งข้อมูลข้าม VLAN อย่างไร และทิศทางของ ACL มีผลอย่างไร | ตั้ง sub-interface สำหรับ VLAN 10, 20, 99 แล้วตรวจ ACL ด้วย traffic จากเครื่อง Staff |
| 5 · OSPF และ EIGRP | OSPF เลือกเส้นทางจาก cost อย่างไร และ EIGRP ใช้เงื่อนไขใดเลือกเส้นทางสำรอง | ตั้ง OSPF Area 0 บน R1–R4 ตรวจ neighbor เปิด MD5 และตัดลิงก์เพื่อดู next hop ที่เปลี่ยน |
| 6 · Gateway Redundancy | HSRP, VRRP และ GLBP ต่างกันอย่างไร ใครตอบ ARP และใครส่งต่อข้อมูล | ตั้ง virtual gateway บนเราเตอร์สองตัว แล้ววัดช่วงที่ ping ขาดระหว่าง failover |
| 7 · 802.1X และการวิเคราะห์แพ็กเก็ต | ใครตรวจสิทธิ์การเข้าพอร์ต และตำแหน่งที่จับแพ็กเก็ตมีผลต่อสิ่งที่มองเห็นอย่างไร | ไล่จาก IP ไป MAC และพอร์ตสวิตช์ ใช้ Kali, tcpdump และ Wireshark ตรวจ VLAN tag และ routing traffic |
| 8 · WAN และการเชื่อม routing domain | PPP, MPLS และ VPN ทำหน้าที่อะไร การรวม prefix ต่างจากการแลก route ข้ามโปรโตคอลอย่างไร | เชื่อม EIGRP กับ OSPF ผ่าน R2 ด้วย redistribution แล้วตรวจเส้นทางไปและกลับหลังตัดและคืนลิงก์ |
