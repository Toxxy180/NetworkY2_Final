# Network Final Lab · 01076040

เว็บภาษาไทยสำหรับเตรียมสอบปลายภาควิชา *Internetworking Standards and Technologies* (มาตรฐานและเทคโนโลยีเครือข่าย) รวม **8 บทเรียน 22 โจทย์ปฏิบัติ และ 120 ข้อสอบฝึก** โดยจับคู่หลักการของแต่ละบทกับการตั้งค่าและการตรวจผลจากใบงานที่ใช้เรียน

[เปิดเว็บทบทวน](https://toxxy180.github.io/NetworkY2_Final/) · [ดูขอบเขตสอบของอาจารย์ (PDF)](./แนวเนื้อหาข้อสอบปลายภาค_Network.pdf) · [เปิดโฟลเดอร์สไลด์และใบงาน](./network_files/)

หากต้องการอ่านออฟไลน์ ให้ดาวน์โหลดไฟล์ `index.html` ที่อยู่ด้านบนสุดของโครงการ แล้วเปิดไฟล์นั้นด้วยเบราว์เซอร์ได้ทันที

## วิธีเตรียมสอบสองส่วน

- **ภาคทฤษฎี** เลือกบทแล้วเปิดแท็บ **ภาคทฤษฎี** ฝึกตอบให้ได้ว่าเทคโนโลยีนั้นคืออะไร ใช้แก้ปัญหาอะไร และต่างจากเรื่องที่ใกล้กันอย่างไร เช่น เมื่อเฟรมมาถึงสวิตช์ สวิตช์ใช้ Source MAC ทำอะไร และใช้ Destination MAC ตอนไหน
- **ภาคปฏิบัติ** เปิดแท็บ **ภาคปฏิบัติ** ของบทเดียวกัน อ่านผังและโจทย์ แล้วลองพิมพ์คำสั่งบนอุปกรณ์ตามใบงานก่อนกด **ดูคำสั่งและวิธีตรวจผล** ตัวอย่างเช่น หลังตั้ง HSRP บน R1 และ R2 ให้ใช้ `show standby brief` ตรวจว่าเครื่องใดเป็น Active เครื่องใดเป็น Standby และทั้งคู่ใช้ Virtual IP เดียวกันหรือไม่

ถ้าจำชื่อคำสั่งได้แต่จำบทไม่ได้ ให้พิมพ์คำสั่ง เช่น `show interfaces trunk` ในช่องค้นหาของเว็บ เมื่ออ่านจบแต่ละบท มีข้อสอบฝึก 15 ข้อพร้อมคำอธิบายเฉลย และมีชุดสุ่มรวม 30 ข้อสำหรับทบทวนข้ามบท โจทย์เหล่านี้เรียบเรียงขึ้นเพื่อฝึกตามขอบเขตสอบ

## หัวข้อและงานปฏิบัติทั้ง 8 บท

| บท | สิ่งที่ควรอธิบายได้ | ตัวอย่างงานที่ใช้ซ้อม |
| --- | --- | --- |
| 1 · Ethernet Switching | สวิตช์เรียนรู้ MAC อย่างไร และ Port Security แต่ละโหมดทำอะไรเมื่อเกิด violation | ตั้งค่า SW1/SW2 จาก console อ่าน MAC address table และกู้พอร์ตที่เข้า `err-disabled` |
| 2 · VLAN และ Trunk | Access port, trunk และ native VLAN ต่างกันอย่างไร และ VTP กระจายข้อมูลอะไร | กระจาย VLAN จาก server ไป client ตรวจ native VLAN ทั้งสองฝั่ง และปิด DTP ที่พอร์ตผู้ใช้ |
| 3 · Spanning Tree | STP เลือก root bridge และพอร์ตสำรองอย่างไร ทำไม BPDU Guard จึงใช้กับพอร์ตปลายทาง | อ่าน Root ID และ Port Role จาก `show spanning-tree vlan 1` แล้วทดสอบ BPDU Guard |
| 4 · Inter-VLAN Routing | Router-on-a-Stick ส่งข้อมูลข้าม VLAN อย่างไร และทิศทางของ ACL มีผลอย่างไร | ตั้ง sub-interface สำหรับ VLAN 10, 20, 99 แล้วตรวจ ACL ด้วย traffic จากเครื่อง Staff |
| 5 · OSPF และ EIGRP | OSPF เลือกเส้นทางจาก cost อย่างไร และ EIGRP ใช้เงื่อนไขใดเลือกเส้นทางสำรอง | ตั้ง OSPF Area 0 บน R1–R4 ตรวจ neighbor เปิด MD5 และตัดลิงก์เพื่อดู next hop ที่เปลี่ยน |
| 6 · Gateway Redundancy | HSRP, VRRP และ GLBP ต่างกันอย่างไร ใครตอบ ARP และใครส่งต่อข้อมูล | ตั้ง virtual gateway บนเราเตอร์สองตัว แล้ววัดช่วงที่ ping ขาดระหว่าง failover |
| 7 · 802.1X และการวิเคราะห์แพ็กเก็ต | ใครตรวจสิทธิ์การเข้าพอร์ต และตำแหน่งที่จับแพ็กเก็ตมีผลต่อสิ่งที่มองเห็นอย่างไร | ไล่จาก IP ไป MAC และพอร์ตสวิตช์ ใช้ Kali, tcpdump และ Wireshark ตรวจ VLAN tag และ routing traffic |
| 8 · WAN และการเชื่อม routing domain | PPP, MPLS และ VPN ทำหน้าที่อะไร การรวม prefix ต่างจากการแลก route ข้ามโปรโตคอลอย่างไร | เชื่อม EIGRP กับ OSPF ผ่าน R2 ด้วย redistribution แล้วตรวจเส้นทางไปและกลับหลังตัดและคืนลิงก์ |
